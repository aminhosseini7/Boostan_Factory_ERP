# Boostan Factory ERP v2 - Phase 1 Foundation

این بسته شروع بازطراحی نسخه کارخانه‌ای است.

اهداف:
- جداسازی قیمت از محصول
- ایجاد تاریخچه قیمت
- آماده‌سازی شیفت و اپراتور
- ایجاد Inventory Ledger
- آماده‌سازی Supplier و Expense

این فایل فقط Foundation است.
ماژول‌های کامل Backend و Frontend در مراحل بعدی روی همین ساختار اضافه می‌شوند.
